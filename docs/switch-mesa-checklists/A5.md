# A5 — First boot on hardware (P0)

Agent-prepared; human runs on Switch. Do not edit NROs; do not guess results.

## NROs (built 2026-11-02, Docker mesa-switch-build-amd64)

- `eidos-mesa.nro` (52,861,732 bytes) + `eidos-mesa.elf` — branch
  `switch/mesa-a4` (A2+A3+A4) + mesa-switch prefix
  `0ff52079.../mesa-install/opt/devkitpro/portlibs/switch`.
  `nm eidos-mesa.elf | grep -c drm_nouveau` = 0;
  `grep -c drm_` = 2 (`T nouveau_drm_del/new`, mesa-switch's own
  in-tree winsys — see A3 notes). EGL/GL/GLESv2/glapi all resolve to
  the prefix (link excerpt in the A3 verification commit).
- `eidos-old.nro` (40,643,364 bytes) + `eidos-old.elf` — `eb7a56a`
  (devkitPro switch-mesa 20.1.0 line). `grep -c drm_nouveau` = 0,
  `grep -c drm_` = 3 (old libEGL's own nouveau_drm_*).
- Both in `~/.cache/eidos/nro-out/` on the build machine.

To rebuild:

```sh
python3 switch/build.py --module build-macos/module/eidos_boot.wasm \
  --build-dir build-switch-mesa \
  --mesa-prefix $HOME/.cache/eidos/mesa-switch/0ff52079ca9e9e837ed27eb95a8d239f439a1864/mesa-install/opt/devkitpro/portlibs/switch
cp build-switch-mesa/eidos.nro /tmp/eidos-mesa.nro

# baseline NRO (old devkitPro switch-mesa 20.1.0 line):
# branch eb7a56a (pre-A3) or same branch with -DEIDOS_SWITCH_MESA_PREFIX=""
python3 switch/build.py --module build-macos/module/eidos_boot.wasm \
  --build-dir build-switch-old
cp build-switch-old/eidos.nro /tmp/eidos-old.nro
```

Expected: `eidos-mesa.nro` links mesa-switch (no `drm_nouveau` symbols;
`nm eidos.elf | grep -c drm_` = 0), `eidos-old.nro` is the 20.1.0 control.

## Copy where

On SD: `sdmc:/switch/eidos/` must contain:

- `eidos.nro` — copy of `eidos-mesa.nro` for runs (a) and (b),
  copy of `eidos-old.nro` for run (c)
- your Pokémon Black or White `.nds` ROM (first by name is used)
- `env.txt` — per run below (exact contents)
- `args.txt` — empty or absent (no extra args)

After each run, copy back `sdmc:/switch/eidos/stderr.txt` and
`sdmc:/switch/eidos/boot.txt`. Take photos/screenshots of title and town.

## env.txt

Standard capture (all runs):

```
EIDOS_NXLINK=1
EIDOS_FPS_LOG=1
EIDOS_RENDERER_REPORT=1
EIDOS_GPU3D_REPORT=1
EIDOS_RENDERER=gl
```

- Run (a) default backend (NVC0): standard capture as-is.
- Run (b) Zink: standard capture plus `MESA_SWITCH_GL_DRIVER=zink`.
- Run (c) baseline `eidos-old.nro`: standard capture as-is
  (old Mesa still defaults to `sdl` unless `env.txt` says `gl`;
  keep `EIDOS_RENDERER=gl` to attempt the GL path; note if it falls back).

Launch args: none extra (title-mode defaults `--resolution 1`).

## Runs (title mode: hold R while starting a game, choose eidos)

- (a) `eidos-mesa.nro` as `eidos.nro`, standard `env.txt` (NVC0).
- (b) `eidos-mesa.nro` as `eidos.nro`, `env.txt` + `MESA_SWITCH_GL_DRIVER=zink`.
- (c) `eidos-old.nro` as `eidos.nro`, standard `env.txt`.

Each run: boot to title, go to the first town, wait 60 s, quit via HOME.

## Send back

For each run (a)(b)(c):

- `stderr.txt` lines: `OpenGL ... (...)`, `presenter ...`,
  `GL_MAX_SAMPLES`, `GL_MAX_INTEGER_SAMPLES` (if logged),
  `GPU3D ...` feature mask / `unsupported` mask, `eidos: ... fps` series,
  any `eidos:`, `wasm trap`, or `svcMapMemory` errors.
- `boot.txt` (how far start-up got).
- Screenshots: title screen, first town (world visible? black world?).
- Note: which backend rendered, world correct at any fps (P0 = title +
  town render correctly, no black world).

Store under `logs/A5/` as `stderr-a.txt`, `stderr-b.txt`, `stderr-c.txt`
plus screenshots. Agent will parse into `switch-plan.md` Results.
