Why software fallback loses on Switch
Pixels: DS 256x192=49k/eye. 720p=921k (~19x one DS screen, 9x both), 1080p=2.07M (42x/21x). Software pays per output pixel in raster_band + fog/edge/AA passes + 2D windows/blend/brightness, all on 1 A57 game thread + 2 workers, in-order 1 GHz cores with small cache, shared memory bus with GPU, battery/thermal throttle. GPU does that in parallel at fixed cost; desktop already shows CPU collapse with scale (31->12 fps 1x->6x). Title/logo capture every frame pins to DS-res anyway (graphics-backends.md:28-32,50-52), so software buys nothing there and blows the 16.7 ms budget (59.83 fps target switch-plan.md:S9) everywhere else. Memory: 1 GiB module + fibers 2 MiB x64 + workers 2 MiB x2 (host/fiber.c:45-52, host/par.c:38-44, switch/README.md:72-81) leaves no headroom for HiRes CPU framebuffers.
